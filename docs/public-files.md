# 公开文件范围

公开源码以 `packaging/public-files.json` 为唯一白名单。发布前运行 `scripts/check_public_files.py`，源码包使用 `scripts/build_source_archive.py` 生成。

## 保留的关键内容

- 生产源码和运行资源：`src/fundlab/`。
- 测试、安装及构建脚本：`tests/`、`scripts/`、`packaging/`；依赖锁、项目配置和根目录启动/安装CMD。
- README、使用说明、更新记录、许可及第三方声明、贡献和安全支持文件、开发约定与Git配置。
- `docs/`中的源码安装、Windows安装、日常维护、日历维护、开发、扩展约定、发布流程、本文件和Release说明。
- `.github/`中的公开检查、候选构建及问题/贡献模板。

构建和测试材料保证源码可继续维护，不将可编辑源码缩减为只有安装器的空壳。工作流只生成待审阅产物，不自动发布。

## 不进入GitHub的内容

个人行情、登录会话、名单、调度账本、备份、虚拟环境、日志、截图、临时测试资料、旧快照及构建目录均不公开。不得上传凭据或个人数据库。

原型记录、阶段安装验收、安装版本机使用验收、首次GitHub准备过程已从公开白名单移出，本机原文件保留。详细验证日志和构建清单保留在本地，不作为使用说明或Release附件。

Release默认只附Windows安装器、白名单源码ZIP和SHA256SUMS.txt。wheel、内部审阅清单、测试安装器和中间产物留在本地或候选构建产物中；项目及第三方许可继续随源码和程序保留。

## 检查边界

模式扫描不保证发现所有敏感内容，发布前仍须审阅实际文件。存在Git仓库时检查实际跟踪集合及历史；`.gitignore`不能移除已跟踪内容，也不能清除既往提交。远端已有文件的移除须在后续同步时核对，本地缩减白名单不代表远端已整理。
