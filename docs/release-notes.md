# QFund 1.1.0：数据管理与价格分析

本次更新增加本地数据维护和价格走势分析，并改善安装及浏览器兼容性。

## 主要变化

- **数据管理**：支持Excel/CSV预览导入、记录新增与编辑、字段保护、基金回收恢复和自选分组。
- **价格分析**：查看最新价格、当前或指定价格的历史分位、均线和分位参考线，支持区间切换、走势缩略图及PNG保存。
- **使用体验**：获取和分析可按分组筛选；改善部分浏览器的页面兼容，以及Windows安装、卸载和任务管理的错误提示。
- **升级保护**：新版安装器增加版本检查，支持同版修复；升级保留原任务启停状态，卸载保留用户数据。

## 下载与升级

普通用户下载 **QFund-Setup-1.1.0.exe**，需要Windows 10/11 x64和新版Microsoft Edge，无需另装Python。开发者可下载 **QFund-1.1.0-source.zip**；附件可用 **SHA256SUMS.txt** 校验。

升级前等待活动任务完成并正常退出工作台，再运行新版安装包，使用原安装位置。数据保存在 `%LOCALAPPDATA%\QFund`，与程序目录分开。首次写入旧行情库时会先备份并升级格式；请保留新版安装包用于修复，升级后不要用旧安装包覆盖。

## 验证与使用范围

本地317项公开离线测试通过，并完成同机隔离的1.0.0升级、同版修复、版本拒绝、任务状态保留、维护回滚和卸载保留数据检查。维护回滚检查不等于真实断电测试，完整跨电脑业务复验暂缓。

安装包未签名。当前主要支持已验证的QDII历史页面，初次取得源站可访问的近期数据，不保证完整历史或全部类别；自动获取日历覆盖2026年。基金数据与分析结果不构成投资建议。
