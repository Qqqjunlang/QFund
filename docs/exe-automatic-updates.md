# EXE版定时获取基金数据：第二步

2026-10-24。这里的自动更新指交易日定时获取基金数据，不是软件自动下载升级。本文保留第二步验收记录；后续[安装向导第三步](windows-installer.md)已完成，当前安装/卸载方式以该说明为准。

## 当前运行方式

- QFund.exe启动原浏览器工作台；在“数据获取”中保存时间并主动启用自动更新。安装程序和工作台启动本身不自动启用任务。
- 同目录QFundWorker.exe是无控制台后台执行器，计划任务传入明确的绝对数据根目录，调用原有调度执行器；不启动网页服务。
- 默认数据仍在当前用户LOCALAPPDATA/QFund，源码版仍使用原项目目录。不会自动迁移或读取原作者数据、profile和名单。
- 计划任务沿用根目录摘要命名，并同时校验Source、执行文件、参数及工作目录。源码与EXE指向同一数据目录但执行动作不同，会报告归属冲突，不能静默接管。
- 用户需已登录Windows，普通权限InteractiveToken，不存密码、不主动唤醒。同日成功去重、提交后只补导出、有限重试与日历覆盖保护沿用原规则。

候选程序位于本机 `dist/exe-step2-2026-10-24/QFund/`。必须保留QFund.exe、QFundWorker.exe和_internal完整配套文件。第一步原型单独保留，本文对应第二步构建，不是正式发布版本。

关闭工作台或网页不会停用自动获取；应在工作台主动停用。移除定时任务保留行情、名单、时间和调度记录。改时间不立即采集，已停用的任务保存新时间后仍保持停用。

## 技术入口与迁移边界

QFund.exe支持 `--schedule-action status/install/disable/remove`，可配合显式绝对路径 `--data-root` 管理对应目录的任务；status只查询，其他动作有实际修改。技术入口不能与diagnose同时使用。

QFundWorker.exe只接受 `--project-root 绝对路径`，不接受伪造时钟或通用脚本执行参数。后台日志仍为该数据根目录下 `.local/scheduled-worker.jsonl`；双击后台执行器不属于用户操作入口。

任务执行文件缺失时明确失败并保留原任务。搬迁程序或更换解释器前先在原位置处理旧任务；升级至不同路径不会自动改写归属，安装向导阶段需要另行验证升级/卸载。原数据目录的调度账本和生效时间不能清空来绕过去重。
