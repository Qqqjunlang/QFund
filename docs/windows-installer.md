# Windows安装版

本文说明安装、升级和数据保留。1.1.0已完成本地候选构建与同机隔离安装验收，尚未发布。

## 普通用户怎样安装

准备Windows 10/11 x64和Microsoft Edge，下载对应版本的完整安装包（本次候选为 `QFund-Setup-1.1.0.exe`），双击后按向导选择安装位置与桌面快捷方式，完成后打开QFund。安装包包含运行环境，无需另装Python、Codex或AI账号。1.0.0为首版；本次更新的实际文件名以最终版本和发布附件为准。

程序仍通过浏览器操作，并保留运行窗口；等待获取、导出或登录结束后，在运行窗口按Ctrl+C正常停止。仅关闭网页不会退出服务。第一次获取前由本人在专用Edge登录，安装包不附带作者数据、账号或任务。

当前候选安装包未签名。Windows或浏览器是否显示提示取决于本机策略，不能将本机测试当作所有电脑都能直接通过的证明；发布前仍须完成干净环境与安全提示检查，不应关闭安全防护来绕过提示。

## 程序与数据位置

| 默认位置 | 用途 |
|---|---|
| `%LOCALAPPDATA%\Programs\QFund` | 程序、后台执行器、资源、文件清单及卸载程序 |
| `%LOCALAPPDATA%\QFund\data` | 行情、导出、名单、时间、调度去重与重试记录 |
| `%LOCALAPPDATA%\QFund\.local` | 专用登录会话、运行记录、锁及安装维护日志 |

安装仅登记当前Windows用户，不要求管理员权限，不改系统Python。桌面和开始菜单入口传入固定用户数据目录。程序位置可以选择，但必须与数据目录分开，不能覆盖无法确认归属的非空文件夹。

源码版仍使用项目目录的数据。本安装包不会自动读取、迁移或接管源码版数据与系统任务。迁移另行制定方案；不能仅复制旧虚拟环境、删除调度账本或共享登录资料。

## 升级、卸载与自动任务

升级软件时，等待活动任务结束、正常退出工作台，再手动运行新安装包，保留原安装位置。安装器暂停自己能严格确认归属的自动任务，完整程序校验通过后恢复原启用或停用状态；没有任务时不创建任务。更换位置须先卸载原程序，不能直接搬动安装目录。

在Windows已安装的应用或开始菜单“卸载QFund”中卸载。卸载会先确认并移除该安装对应的Windows自动任务，再移除程序和快捷方式；保留全部用户数据与本机登录会话。以后重新安装仍使用同一用户数据目录。需要清理私人资料时另行由本人处理，卸载器不提供默认删除数据选项。

安装/卸载遇到工作台、登录、获取或后台任务正在运行时停止并提示，不能强制结束它们。归属不符、任务状态不可确认、程序清单缺失时停止，不能将查询失败解释为“未安装”。中断后检查数据目录 `.local/installer-journal` 的记录；若程序已部分变动，自动任务保持停用或移除，恢复完整程序并核对后再启用。

新版安装、升级、卸载与自动任务管理共用同一个 PowerShell 调用。QFund 仅在该子进程指定 `RemoteSigned`，组织下发的执行策略仍优先。遇到策略拦截、权限不足、任务计划服务异常、超时或返回结果无效时，按提示核对对应原因。超时后先核对任务状态，再决定是否重试。[Windows PowerShell 执行策略](https://learn.microsoft.com/en-us/powershell/module/microsoft.powershell.core/about/about_execution_policies?view=powershell-5.1)

这里的软件升级是手动安装新版；“自动更新”仍指交易日获取基金数据，没有实现软件联网下载更新。自动获取需要本人在工作台主动启用，操作和执行规则见[使用说明](../使用说明.md)。

### 版本与回退

新版安装器持有维护锁后，先检查已有程序版本、三库版本与轻量完整性、时间设置，检查通过才暂停任务和替换程序。拒绝低版本覆盖，允许同版修复，写入后再次核对版本和文件完整性。

旧行情库在首次明确写入时先生成一致性备份，再事务升级至schema3；只读查询不触发迁移。升级保留名单、更新时间、生效点和调度去重/预算。程序归属、版本或任务状态无法确认时停止，不应删除安装标记或清单绕过检查。

已经分发的旧安装器带有旧代码，仍可能覆盖新程序。升级后请保留新版安装包用于修复；旧版拒绝写入升级后的行情库，不代表可安全回退。回退需另行准备匹配的程序与完整数据快照，不能只恢复行情而丢弃名单和调度账本。

卸载继续核对程序和任务归属，但不因业务数据版本较新而删除或修改用户资料。

## 验证范围

1.1.0已通过同机隔离的1.0.0升级、同版修复、未来版本清单拒绝、真实测试任务启停保留、维护助手回滚及卸载保留数据检查。测试使用独立登记与合成资料，详细过程留在本地。

维护回滚覆盖程序未变时恢复任务、程序已变时保持停用，以及完整安装包修复；未做真实断电或强杀安装器测试。完整跨电脑业务复验暂缓，原旧浏览器未复测，推荐新版Edge。构建方法见[发布流程](releasing.md)。
