# Windows安装版：第三步

2026-10-24。已生成带安装向导、快捷方式和卸载入口的候选EXE安装包。本机隔离安装、覆盖安装、运行保护、任务保留与卸载实测通过，尚未公开发布或完成第二台电脑验收。

## 普通用户怎样安装

准备Windows 10/11 x64和Microsoft Edge，下载完整的 `QFund-Setup-0.3.0.exe`，双击后按向导选择安装位置与桌面快捷方式，完成后打开QFund。安装包包含运行环境，无需另装Python、Codex或AI账号。当前0.3.0沿用内部版本，首次公开发布版本尚未确定。

程序仍通过浏览器操作，并保留运行窗口；等待获取、导出或登录结束后，在运行窗口按Ctrl+C正常停止。仅关闭网页不会退出服务。第一次获取前由本人在专用Edge登录，安装包不附带作者数据、账号或任务。

当前候选安装包未签名。Windows或浏览器是否显示提示取决于本机策略，不能将本机测试当作所有电脑都能直接通过的证明；发布前仍须完成干净环境与安全提示检查，不应关闭安全防护来绕过提示。

## 程序与数据位置

| 默认位置 | 用途 |
|---|---|
| `%LOCALAPPDATA%\Programs\QFund` | 程序、后台执行器、资源、文件清单及卸载程序 |
| `%LOCALAPPDATA%\QFund\data` | 行情、导出、名单、时间、调度去重与重试记录 |
| `%LOCALAPPDATA%\QFund\.local` | 专用登录会话、运行记录、锁及安装维护日志 |

安装仅登记当前Windows用户，不要求管理员权限，不改系统Python。桌面和开始菜单入口传入固定用户数据目录。程序位置可以选择，但必须与数据目录分开，不能覆盖无法确认归属的非空文件夹。

源码版仍使用项目目录的数据。本安装包不会自动读取、迁移或接管源码版数据与系统任务。迁移另行制定方案；不能仅复制旧虚拟环境、删除调度账本或共享登录资料。

## 升级、卸载与自动任务

升级软件时，等待活动任务结束、正常退出工作台，再手动运行新安装包，保留原安装位置。安装器暂停自己能严格确认归属的自动任务，完整程序校验通过后恢复原启用或停用状态；没有任务时不创建任务。更换位置须先卸载原程序，不能直接搬动安装目录。

在Windows已安装的应用或开始菜单“卸载QFund”中卸载。卸载会先确认并移除该安装对应的Windows自动任务，再移除程序和快捷方式；保留全部用户数据与本机登录会话。以后重新安装仍使用同一用户数据目录。需要清理私人资料时另行由本人处理，卸载器不提供默认删除数据选项。

安装/卸载遇到工作台、登录、获取或后台任务正在运行时停止并提示，不能强制结束它们。归属不符、任务状态不可确认、程序清单缺失时停止，不能将查询失败解释为“未安装”。中断后检查数据目录 `.local/installer-journal` 的记录；若程序已部分变动，自动任务保持停用或移除，恢复完整程序并核对后再启用。

这里的软件升级是手动安装新版；“自动更新”仍指交易日获取基金数据，没有实现软件联网下载更新。自动获取需要本人在工作台主动启用，实际执行规则见[第二步说明](exe-automatic-updates.md)。

## 维护人员构建

先按[EXE原型记录](exe-prototype.md)在独立环境准备目录式程序，再使用Inno Setup 6.7.3编译。编译器来自[Inno Setup官方发布](https://github.com/jrsoftware/issrc/releases/tag/is-6_7_3)，本轮下载后核对了有效的Pyrsys B.V.签名；编译器不随项目源码附带。

```powershell
.\.venv\Scripts\python.exe scripts\build_installer.py --program-dir 完整程序目录 --output-dir 新的输出目录 --compiler ISCC.exe完整路径
```

构建脚本拒绝覆盖已有输出，按程序白名单生成program-manifest.json、bundle-files.txt及安装器SHA256清单；不读取data/profile。`packaging/windows/installer.iss`定义向导与生命周期握手，`zh-CN.isl`定义中文，ICO来自已选定SVG。维护助手复制到私有临时目录后持有独占安装锁，跨越文件替换/移除全程；运行入口持共享锁。任务管理仍沿用原有严格身份校验，不复制调度或采集算法。

`--test-root`仅供维护验证，必须指向项目.local内独立目录，会使用独立AppId、数据和快捷方式位置，不可当作公开安装包分发。正常候选使用稳定的QFund.Desktop身份。内置Python/依赖和构建资源沿用前两步方案，旧工具弃用警告、通用CPython重建及第三方可分发内容/许可审查仍待发布前处理。

后续本机已安装候选的本人登录、真实获取、查询、Excel/CSV下载及PNG分析保存已通过；用户另反馈第二台电脑已安装成功并能打开，见[实际使用验收](installed-use-acceptance.md)。用户决定暂缓第二台电脑的其余业务复验，继续许可证、公开文件审查及发布材料准备。Python是否预装等环境信息尚未确认，不称已完成无Python干净系统验收。不会因验收进展自动发布或迁移现有数据。
