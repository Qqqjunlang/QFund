# 安装入口验收

日期：2026-10-24。本轮实现源码安装入口，未生成正式发布包或EXE，没有在第二台电脑上操作。

## 实现内容

- 根目录“安装环境.cmd”：查找可用Python，或使用临时QFUND_PYTHON指定解释器；已有项目环境优先检查。保留窗口显示结果和错误码，CMD保持CRLF。
- scripts/install_environment.py：标准库引导，验证源码完整性、版本及可写目录，使用项目安装锁；创建项目.venv并安装锁定依赖及可编辑源码。
- 安装完成核对实际导入目录、数据根目录、依赖/项目版本、Edge、网页/图表/日历/PS1资源及pip check。无业务调用，不启动登录、采集、导出或自动任务。
- 既有环境仅检查，失败保留原件；依赖安装失败停止，不误报成功，不自动删除或覆盖半成品环境。

## 实际验证

| 内容 | 本轮结果 |
|---|---|
| 环境 | 同一台Windows电脑，Python 3.12.14；未用系统旧Python替代 |
| 全新安装 | 两个不同的中文/空格目录，各自创建独立.venv、安装10项锁定依赖及本项目，通过版本、路径、资源和pip check |
| CMD入口 | 一个副本通过CMD＋明确指定Python解释器完成实际安装，路径及wheelhouse参数含中文/空格 |
| 重复安装 | 从另一工作目录运行安装CMD，返回成功且只检查；依赖METADATA指纹不变 |
| 保护检查 | 9项通过：源码不完整、旧Python、既有环境/数据保留、既有检查失败、离线包目录缺失、依赖失败、并发锁、CMD路径等 |
| 启动器回归 | 14项通过，使用新隔离环境解释器运行；与9项安装检查合计23项，无跳过 |
| 实际启动 | 空数据副本两轮隐藏专用控制台启动，首页、JS、CSS、SVG及概况API读取正常，基金为空；重复启动复用 |
| 退出与重开 | 最终两轮均发送真实Windows CTRL_C_EVENT，服务正常退出0并停止监听，随后可以重开 |
| 副本数据 | 未创建行情data目录、专用浏览器profile或系统任务，未打开浏览器 |

运行验证使用实际安装的环境和源码。为避免工具宿主继承的CTRL_C忽略属性，最终测试子进程入口显式恢复标准控制台信号处理后调用原launcher.main；没有修改生产启动器或新增退出HTTP接口。HTTP核对不等于浏览器渲染或真人登录采集验收。

## 故障与边界

本轮首次联网下载被网络沙箱拦截；按权限流程重试后仍遇TLS连接失败，没有关闭证书验证或改用不安全源。随后使用本机pip缓存及既有目录中10个原始wheel完成离线安装，未从已安装目录重新打包依赖。结果证明本轮离线安装路线，不证明联网下载已经跑通。

初次进程验收误将虚拟环境入口PID当作实际服务PID；另一轮工具控制台继承了忽略CTRL_C的状态，未正常退出。已核对本轮隔离服务身份后清理，未将强制清理记作正常退出通过；最终两轮正常退出另有日志记录。正式服务和其他用户进程未被结束。

第二台电脑、其他Python版本/架构、正常用户安装后的自动发现Python组合、企业代理环境、真人源站登录与获取仍待后续验证。日历仍仅覆盖2026，任意wheel安装与数据迁移未实现。许可证、正式发布版本、CI和GitHub发布未在本步执行。

私有日志和隔离环境保留在本地忽略目录，发布说明不包含个人路径、数据库或登录资料。当前工作目录已有数据和环境继续使用原件，不需要为了验收运行安装脚本。
