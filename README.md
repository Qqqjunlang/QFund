# QFund

Windows本地基金数据工具：从集思录获取基金近期数据，持续保存在自己的电脑上，再查询、导出和做数据分析。

**本机运行 · 浏览器界面 · 数据本地保存 · 无需AI账号或API Key**

## 快速开始

### 普通使用者：Windows安装版

1. 在本仓库的 **Releases** 下载 `QFund-Setup-1.0.0.exe`。
2. 双击安装，按向导完成；从开始菜单或所选桌面快捷方式打开QFund。
3. 浏览器打开后，按下文完成首次使用。

需要 **Windows 10/11 x64和Microsoft Edge**，**无需另装Python。**

### 开发者：源码运行

安装Python 3.12，完整解压或克隆源码，然后双击 **安装环境.cmd**。检查完成后双击 **启动工作台.cmd**。已有项目环境只检查，不自动覆盖。

源码入口声明支持Python 3.11+，当前实测基线为3.12；其他组合未承诺通过。手动命令、网络及离线安装见[源码安装说明](docs/installation.md)。

### 第一次使用

1. 进入“数据获取”，点击“专用Edge登录”，由本人完成集思录登录。
2. 按基金代码或名称查找，确认一只已支持的基金，再获取数据。
3. 获取完数据之后可以进行愉快的分析与数据下载。

保留运行窗口。结束时等待获取、导出或登录任务完成，再在运行窗口按 **Ctrl+C** 停止。只关闭网页不会停止服务，也不会停用独立的Windows自动任务。

## 基本功能（v1.0.0功能）

- 单基金真实数据获取，按日期累积去重，同日修订保留记录。
- SQLite本地保存，自动导出Excel、CSV和来源说明；导出失败可仅重试导出。
- 按价格日期查询、筛选和下载。
- 溢价率时序、历史分位、近N日平均、区间切换和PNG保存。
- 自动更新名单、北京时间设置和独立Windows后台任务。
- 安装版覆盖安装保留原任务启停状态；卸载移除对应任务并保留用户数据。

当前主要验证QDII历史页面族。目录中出现其他类别不代表其历史采集已支持；首次取得源站可访问的近期窗口，以后持续积累，不承诺成立以来完整历史。
