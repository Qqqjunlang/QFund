# QFund

Windows本地基金数据工具：从集思录获取基金近期数据，持续保存在自己的电脑上，再查询、导出和分析溢价率。

**本机运行 · 浏览器界面 · 数据本地保存 · 无需AI账号或API Key**

## 安装

### 普通使用者：Windows安装版

1. 在本仓库的 **Releases** 下载 `QFund-Setup-版本.exe`。
2. 双击安装，按向导完成；从开始菜单或所选桌面快捷方式打开QFund。
3. 浏览器打开后，按下文完成首次使用。

需要 **Windows 10/11 x64和Microsoft Edge**，无需另装Python。当前是首次发布准备，尚未创建远端Release；不要把GitHub的“Source code”ZIP当作安装EXE。具体位置、升级和卸载见[Windows安装说明](docs/windows-installer.md)。

### 开发者：源码运行

安装Python 3.12，完整解压或克隆源码，然后双击 **安装环境.cmd**。检查完成后双击 **启动工作台.cmd**。已有项目环境只检查，不自动覆盖。

源码入口声明支持Python 3.11+，当前实测基线为3.12；其他组合未承诺通过。手动命令、网络及离线安装见[源码安装说明](docs/installation.md)。

## 第一次使用

1. 进入“数据获取”，点击“专用Edge登录”，由本人完成集思录登录。
2. 按基金代码或名称查找，确认一只已支持的基金，再获取数据。
3. 在“数据查询”中筛选日期、下载Excel或CSV；在“数据分析”中查看图表并保存PNG。
4. 需要定时获取时，再把已有基金加入自动更新名单、保存时间并主动启用。

保留运行窗口。结束时等待获取、导出或登录任务完成，再在运行窗口按 **Ctrl+C** 停止。只关闭网页不会停止服务，也不会停用独立的Windows自动任务。

## 功能

- 单基金真实数据获取，按日期累积去重，同日修订保留记录。
- SQLite本地保存，自动导出Excel、CSV和来源说明；导出失败可仅重试导出。
- 按价格日期查询、筛选和下载。
- 溢价率时序、历史分位、近N日平均、区间切换和PNG保存。
- 自动更新名单、北京时间设置和独立Windows后台任务。
- 安装版覆盖安装保留原任务启停状态；卸载移除对应任务并保留用户数据。

当前主要验证QDII历史页面族。目录中出现其他类别不代表其历史采集已支持；首次取得源站可访问的近期窗口，以后持续积累，不承诺成立以来完整历史。

## 数据与自动更新

| 运行方式 | 数据根目录 |
|---|---|
| Windows安装版 | `%LOCALAPPDATA%\QFund` |
| 源码版 | 当前项目目录 |

根目录的`data/`保存行情、导出、名单、时间和调度记录，`.local/`保存专用登录会话与运行记录。安装版不会自动迁移或读取源码版资料。不要公开这些目录，也不要通过删除调度记录强制重采。

自动获取要求安装任务的Windows用户已登录，程序不主动唤醒电脑，待机或系统分派可能导致延迟。当前交易日日历覆盖 **2026年**，覆盖外暂停自动执行；维护步骤见[日历说明](docs/trading-calendar-maintenance.md)。这里的自动更新指基金数据，不是软件联网升级。

## 验证与已知边界

本机已验证安装、覆盖安装、卸载保留数据，以及本人登录、真实获取、查询、Excel/CSV下载和PNG分析保存。用户反馈第二台电脑安装成功并能打开，其余跨电脑业务复验暂缓。[验收范围](docs/installed-use-acceptance.md)

安装候选尚未签名。账号权限、源站变化和网络会影响获取；本项目不提供源站账号或数据访问授权。基金数据和分析结果不构成投资建议。
